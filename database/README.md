# Database

Esta pasta contém scripts e documentação relacionados ao banco de dados Oracle.

## Conteúdo

- Scripts DDL (CREATE TABLE, INDEX, etc.)
- Scripts DML (INSERT, UPDATE, DELETE)
- Scripts de inicialização
- Diagramas ER
- Dicionário de dados
- Scripts de backup e restore

Todos os scripts devem seguir as boas práticas de segurança e performance.
