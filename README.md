# manus-oracle-apex
Base operacional para uso do Manus como equipe especializada em Oracle APEX, Oracle Database, PL/SQL, ORDS, UI/UX e FONAR Digital.

## Uso rápido
Digite um comando e uma frase curta:
- `/APEX-MASTER melhorar página 28`
- `/APEX-ERRO ORA-06502 página 35`
- `/APEX-FORM criar cadastro`
- `/FONAR-MASTER revisar fluxo de envio`
- `/WEB-MASTER modernizar esta tela`
- `/PROMPT-ENGINEER melhorar este pedido`

O `SKILL.md` funciona como orquestrador. `agents/` contém especialistas, `prompts/` contém módulos operacionais, `workflows/` define pipelines, `references/` contém regras e `docs/FONAR/` + `database/` são fontes do projeto.

## Regra crítica
Nenhum agente deve inventar estrutura. Para FONAR, documentação e banco reais prevalecem sobre conhecimento genérico.
