# agents

Esta pasta contém agentes, configurações e scripts relacionados a agentes automatizados usados no projeto (por exemplo, automações, agentes de integração, wrappers de IA, etc.).

Sugestões de organização dentro de agents/

- configs/    ← arquivos de configuração de cada agente (YAML, JSON)
- scripts/    ← scripts de inicialização ou integração
- examples/   ← exemplos de uso e instruções de execução

Boas práticas
- Cada agente deve ter um README ou um arquivo de configuração descrevendo dependências e como executá-lo.
- Use nomes claros e versionamento semântico nos arquivos de configuração quando aplicável (ex.: agent-name.v1.yaml).

Se desejar, posso criar as subpastas `configs`, `scripts` e `examples` e adicionar `.gitkeep` ou README em cada uma.
