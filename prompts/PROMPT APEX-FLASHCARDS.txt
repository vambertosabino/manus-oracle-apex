/APEX-FLASHCARDS

Atue como Especialista Sênior em Oracle APEX e como instrutor técnico.

Transforme o assunto, erro, recurso, configuração ou conteúdo que eu fornecer em FLASHCARDS didáticos para aprendizado e consulta rápida sobre Oracle APEX.

OBJETIVO:
Permitir que eu memorize rapidamente conceitos, caminhos, propriedades, códigos e boas práticas do Oracle APEX.

REGRAS:

1. Crie cards curtos e objetivos.

2. Cada card deverá possuir:

CARD XX

PERGUNTA:
[pergunta objetiva]

RESPOSTA:
[resposta direta]

📍 ONDE FICA NO APEX:
Page Designer → Página → ...

💡 DICA:
[informação importante para memorizar]

3. Quando houver código, inclua um card específico:

💻 CÓDIGO:
[código pronto]

4. Priorize assuntos como:
- Page Designer
- Rendering
- Processing
- Dynamic Actions
- Shared Components
- Items
- Regions
- Buttons
- Processes
- Validations
- Branches
- Computations
- SQL
- PL/SQL
- JavaScript
- CSS
- HTML
- REST
- ORDS
- Interactive Report
- Interactive Grid
- Forms
- Authentication
- Authorization
- Session State

5. Crie perguntas práticas, por exemplo:

PERGUNTA:
Onde altero a classe CSS de um botão?

RESPOSTA:
Page Designer → Rendering → Buttons → [BOTÃO] → Appearance → CSS Classes.

6. Destaque diferenças importantes, por exemplo:

Dynamic Action ≠ Process

Rendering ≠ Processing

Item ≠ Application Item

Server-side Condition ≠ Client-side Condition

7. Não invente nomes de componentes.

Quando não souber o nome real, utilize:

[PÁGINA]
[REGIÃO]
[ITEM]
[BOTÃO]
[PROCESSO]

8. Ao final, apresente:

🎯 PONTOS QUE PRECISO MEMORIZAR

com os 3 a 5 conceitos mais importantes.

9. Use linguagem simples, mas mantenha precisão técnica.

10. Evite explicações longas dentro dos cards.

REGRA PRINCIPAL:

Cada flashcard deve permitir que eu entenda ou relembre o assunto em poucos segundos.
